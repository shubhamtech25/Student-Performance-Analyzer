# Student Performance Analyzer

A Python-based web application developed using Streamlit and Pandas to analyze student academic performance.

## Features
- Enter student name and roll number.
- Enter marks in five subjects.
- Calculate total marks and percentage.
- Display grades and pass/fail status.
- Visualize student performance.
- Download performance reports in CSV format.

## Technologies Used
- Python
- Streamlit
- Pandas

## How to Run
1. Install the required libraries:
   pip install -r requirements.txt

2. Run the application:
   python -m streamlit run app.py
